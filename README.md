# 穹野坐标 · 微信小程序 0.4.0

本程序根据出生日期、时间和地点，在设备内生成占星星盘、世界行星线及城市主题推荐。支持中国大陆及港澳台筛选、重定位星盘、保存图片和微信分享。内容仅供兴趣参考，主题分数不是现实成功概率。

**0.4.0 为源码公开版本。** [版本发布页](https://github.com/ericismyeldestson/qiongye-coordinates/releases/tag/v0.4.0)提供完整可重建源码包及 SHA-256 校验值。本次发布的是项目源码，微信小程序的审核和上线状态独立管理。 软件按 **AGPL-3.0-only** 提供；第三方数据及编译运行支持分别保留各自许可。完整清单见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。每个小程序版本应对应保留同版本源码；版本归档包含第三方源文件和构建材料。

## 与旧版的关系

项目早期从 StarMapper 网页功能移植。0.4.0 已移除从原站抽取的计算模块、城市推荐数据及权重、翻译解释、WASM/加载器和地球纹理，改用下列可追溯来源。本项目与 starmapper.com、Astrodienst、GeoNames 等机构没有隶属或背书关系。

历史旧版由维护者在本地另行备份，不属于本公开仓库和源码包。保留历史文件不会改变旧文件本身的许可状态。

## 打开和使用

使用微信开发者工具打开包含 `project.config.json` 的目录。无需 npm 依赖或 npm 构建。项目内 AppID 是公开项目标识，不是密钥；其他维护者应使用自己有权使用的 AppID 或开发者工具测试号。账号上传、代码审核、备案、认证和正式发布是分别操作的步骤。

1. 填写出生日期、当地钟表时间和出生地点。首页有上海演示及李小龙、姚明公开资料示例；来源说明保留资料等级和链接，不能把示例修改后继续称为该名人的真实排盘。
2. 城市库包含 4,412 个离线地点，支持中文/英文搜索；也可明确采用手动坐标和时区。城市中心坐标不等于精确出生地址。
3. 结果页包含「推荐地点」「世界行星线」「本命星盘」。选择城市可查看主题解释和重定位星盘；同一出生时刻的天体位置保持不变，宫位按新地点计算。
4. 推荐范围为「全部 / 中国」，中国包括大陆及港澳台地区。全球 891 个候选、中国 198 个候选；未列为候选的已收录城市仍可搜索分析。
5. 地图支持 12 个天体、ASC/DSC/MC/IC 共 48 条线，筛选、拖动、缩放及选点。地图仅作全球概览，没有行政边界或道路导航。
6. 可保存当前结果图、由微信原生入口分享到朋友圈或选择好友。接收者通过分享参数重新计算；打开分享面板不代表发送成功。
7. 首页底部的「许可与源码」显示许可原文及版本对应的源码链接。当前版本可复制上方版本发布页地址，获取对应源码。

## 数据与计算架构

| 部分 | 来源与实现 |
|---|---|
| 天体、四轴和宫位 | 官方 Swiss Ephemeris 2.10.03；固定源码提交 `91339e55d2351f32548d8a8d5bca6aa93b4f6da7`；项目自行编译 WASM |
| 天体范围 | 日、月、水、金、火、木、土、天王、海王、冥王、凯龙、真北交点 |
| 行星线 | `core/sky-lines.js` 独立球面几何实现，依据赤道坐标和恒星时构造四轴地平线；纬度步长 0.25° |
| 城市候选 | GeoNames CC BY 4.0：百万人口城市加各国家/地区人口前二，明确覆盖香港、澳门、台北，按 GeoNames ID 排序 |
| 主题分数 | `core/place-rules.js` 独立定义权重；350 km 内的线路按距离递减计分；同分按候选顺序 |
| 解释文案 | `data/place-copy.js` 为本项目重新编写，不含原站译文；不作现实结果保证 |
| 时区 | IANA 历史偏移的固定预计算表；支持夏令时空缺与重复时刻、北京时间/新疆时间选择 |
| 地图与装饰地球 | Natural Earth 公共领域陆地轮廓；首页表面在本地绘制，城市亮点作装饰，不是实测夜光影像 |

新推荐规则和候选范围会产生与 0.3.2 不同的排名；不再以原站输出相同作为验收条件。星历数值由同一套官方 C 源码的原生构建对照，行星线由几何不变量测试验证。主题推荐只是占星解释规则，没有计入就业、签证、成本或其他现实条件。

支持当地出生日期 1900—2099 年、热带黄道、地心位置、公历；支持 Placidus 和整宫制。高纬度 Placidus 不可用时保留天体及地图并说明错误，不悄悄更换宫制。主要相位采用合/冲 8°、刑/拱 6°、六合 4°的客户端显示规则。

首次获取小程序及星历分包由微信下载；后续计算不请求原站、开发者后台或在线地图。出生资料不主动上传或建立持久历史记录。用户主动保存、复制、分享会生成图片、剪贴板或分享参数副本；关闭小程序不会撤回这些副本。

## 完整源码与可重建方式

源码包包含应用源码、官方 Swiss C 源码/头文件、星历数据、城市源目录、陆地 GeoJSON、许可、数据生成和构建脚本、固定测试样本。没有原站构建目录或当前开发者电脑路径依赖。

前提：Node.js 22、Python 3、C 编译器、tar；重编 WASM 需要官方 Emscripten SDK **4.0.15**。常规运行和测试不要求安装编译工具链，使用已附带且登记哈希的构建产物。

```sh
# SDK 可放在源码目录之外；不需要复制开发者本机 SDK。
git clone https://github.com/emscripten-core/emsdk.git
cd emsdk
git checkout 4.0.15
./emsdk install 4.0.15
./emsdk activate 4.0.15
. ./emsdk_env.sh
cd /path/to/qiongye-coordinates-0.4.0
npm run build:swiss
npm test
npm run check
npm run audit:licenses
```

亦可将 `QIONGYE_EMCC` 指向该 SDK 的 `upstream/emscripten/emcc`。构建脚本核对官方源文件哈希、编译器版本和所有构建产物；`vendor-manifest.json` 记录完整参数。固定的官方 4.0.15 SDK 对应构建标识 `b412b6307e541b93dd93f01b61181e15c17302ec`。编译器和其未修改的标准运行库由官方 SDK 提供，许可证随项目保留。

可选择重建其他产物：

```sh
node scripts/prepare-world.cjs
node scripts/prepare-recommendations.cjs
node scripts/prepare-licenses.cjs
# 重新生成原生参考值需要本机 C 编译器；不是测试时自动重写预期值。
python3 scripts/reference-fixtures.py
# 可选数据更新，使用本机 Python zoneinfo 的时区版本，结果可能变化：
python3 scripts/prepare-locations.py
```

普通构建直接使用已附带的时区预计算表。更新时区数据库、城市数据或 Node/ICU 显示名称版本属于数据更新，应复核变化并更新来源清单。中文地区名由 Node Intl/CLDR 的标准接口产生，无单独导入的原站名称表。

## 来源和发布检查

`runtime-provenance.json` 为每个运行文件登记来源类别及 SHA-256。新文件必须先查明许可、登记来源，再手动更新清单；哈希仅用于检测后续变化，本身不是版权授权证明。

```sh
npm run audit:licenses   # 来源、许可、资源/构建输入一致性
npm run audit:seal       # 确认合法修改后更新已登记文件哈希；拒绝未登记文件
npm run source:pack      # 准备本地源码归档；不上传、不代表公开源码已提供
npm run check:release    # 校验来源和源码发布配置；仍需核验实际下载地址
```

维护后续版本：

1. 将匹配版本的完整源码托管到可公开下载的位置，包含本文件、许可、构建脚本和第三方源码/数据。保留对应版本归档，不仅提供不匹配的最新分支。
2. 在 `source-release.json` 填入真实 HTTPS `sourceURL`，只有确认公开可用后才将 `sourcePublished` 设为 `true`。版本与 `package.json` 必须相同。
3. 在独立发布目录准备目标版本的许可页和完整源码，复核后更新清单并运行检查；完成 GitHub 发布和下载校验后，再同步小程序工作目录。已正式发布的版本归档应保留，后续改动使用新版本号。
4. 只有用户另行授权才上传小程序代码、送审或发布。本地脚本不会替开发者工具或微信后台执行这些动作。发布检查检查配置及文件，不能代替对源码 URL 实际可达性和平台分发条款的核对。

```sh
node scripts/prepare-licenses.cjs
npm run audit:seal
npm test
npm run check

```

## 测试证据与限制

- 固定样本覆盖 12 个 UTC 时刻、每个时刻 12 个天体，以及 120 组 Placidus/整宫宫位；与同源官方原生构建比较，数值容差 `1e-7` 度。
- 几何测试验证赤道变换、升落线地平线条件、球面距离、日期变更线和 350 km 边界。
- 页面状态、真实生日示例、历史时区、地图/推荐/重定位一致性、分享参数冷启动恢复、海报生成和相册接口分支均有测试。
- 许可测试会注入未知资源、破坏 WASM、移除许可，确认检查失败；未发布源码的版本不能通过发布检查。
- 这些测试不等于真机微信保存/发送成功，也不等于审核通过或法律意见。旧版的真机验收不能自动视为新官方构建的真机验收。

## 目录

- `miniprogram/`：实际运行包；含主页、结果、隐私、许可页及本地计算模块。
- `native/`：本项目编写的 Swiss C 适配层。
- `third_party/`：固定官方源码、星历和数据源、许可来源与哈希。
- `scripts/`：构建、数据生成、测试样本生成、许可检查和源码打包。
- `tests/`：行为与数值测试，原生计算参考值。
- `verification/`：本机验证证据及历史备份，不纳入源码包。
- `release/source/`：打包脚本的本地产物目录；公开归档以对应 GitHub Release 为准。
